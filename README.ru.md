# Detective Story Reverse

Модуль Foundry VTT v13 для системы dnd5e 5.3.3: игроки ищут улики на сценах, собирают их в личный список, обмениваются ими и выставляют на доску улик с нитями, а ГМ и профайлеры ведут дела, досье подозреваемых и таймлайны.

Интерфейс на русском и английском: язык выбирается по языку клиента Foundry. English version: `README.md`.

Модуль — глубокая переработка прототипа Investigation Re:Verse. Движок доски и режим сосредоточения взяты из прототипа (доска основана на Investigation Board, Mordachai, MIT); хранение улик, обмен, окна и проверки написаны заново.

## Установка

1. Установите и включите модуль **socketlib**.
2. В Foundry: «Дополнения → Установить модуль» и вставьте адрес манифеста:
   `https://github.com/Paragon-Re-verse/detective-story-reverse/releases/latest/download/module.json`
3. Включите модуль в мире на системе dnd5e.

## Что умеет

- **Улики и типы.** ГМ создаёт улики в окне ГМ: изображение, название, тип, описание, теги; настройки обнаружения; вид карточки для доски с живым превью. Встроенные иконки типов и свои типы.
- **Зоны поиска.** Любой тайл становится зоной на вкладке «Улика» в его настройках. Режимы «Фон без токена» и «Боевая карта с токеном» (с проверкой расстояния). Бросок навыка, характеристики или формулы средствами dnd5e, ограниченное число попыток, остаток попыток игроку не виден. ГМ видит над зонами подписи: улика, проверка, СЛ, радиус и попытки.
- **Режим сосредоточения.** Каждый игрок включает сам; подсвечиваются зоны текущей сцены, где он ещё ничего не нашёл. Подсказка у курсора: «Осмотреть», «Выберите токен» или «Подойдите ближе: ещё ≈ N фт».
- **Список улик игрока.** Плитка или строки, сортировка (новые, по названию, по типу, по делу), поиск по названию и тегам, фильтр по типу, значок «новая», личные заметки (значок на карточке), «Показать в чате», «Выставить на доску», передача одной улики или списком.
- **Папки улик** в списке игрока, в библиотеке ГМ и в каждом деле: название, цвет, иконка или картинка, подпапки до 4 уровней, ручной порядок, перетаскивание. Папку целиком можно передать другому игроку, ГМ может выдать её игроку, профайлер — перенести из своего списка в дело.
- **Выдача и обмен.** ГМ выдаёт улики сразу (в том числе игрокам не в сети), в том числе перетаскиванием шаблона из библиотеки на игрока. Игроки передают улики друг другу без ведущего: окна «Да / Нет» по очереди, предупреждение о дубликатах, ГМ получает скрытое сообщение.
- **Анимация находки** по центру экрана (отключается в настройках модуля).
- **Досье подозреваемых** с личными заметками каждого игрока. Удалённое досье остаётся в делах архивным подозреваемым.
- **Цепочки улик**: зона может требовать улики; пока их у игрока нет, зоны для него не существует. Переключатель «Подписи зон» для ГМ одним нажатием.
- **Версии и разгадка**: профайлеры выдвигают версии (подозреваемые, мотив, способ, улики); ГМ сверяет их с разгадкой дела, отмечает «верно / неверно» и при закрытии дела решает, показывать ли разгадку.
- **Уровни улики**: до 6 уровней информации у улики, их открывает ГМ или игрок кнопкой «Изучить».
- **Несколько дел одновременно**: участники дела, вкладки дела, архив досье и фильтры по делу в окне ГМ для долгих кампаний.
- **Прогресс дела** для ГМ и профайлера: таблица «улика × игроки» с местами, цепочками и попытками.
- **Дела, таймлайн, архив.** Нумерация дел, прикрепление улик перетаскиванием, теги дел на уликах игроков, закрытие и переоткрытие (закрытое дело не меняется), таймлайн по реальному времени или с равными расстояниями (интервалы, места, цвета, связанные улики и подозреваемые, скрытые события и события «по улике»), архив закрытых дел и архивных подозреваемых по делам.
- **Доска улик.** Карточки улик шести видов (в том числе видеокассета VHS с файлом .mp4/.webm: она играет в плеере с эффектом плёнки, а ГМ может показать её всем), стикеры, фотокарточки подозреваемых, нити выбранного цвета, «Подробнее», готовые сцены в компендиуме. Пока тянешь нить, правый клик по пустому месту создаёт там карточку любого вида (или выставляет улику и подозреваемого) уже с нитью.
- **Штампы.** Правый клик по фотокарточке, карточке-заметке, стикеру или раздаточному материалу → «Штамп»: «Секретно», «Пропал без вести», крест от руки, «Улика», «Погиб», «Вымарано» или «Убрать штамп». Штамп ложится под курсор. Папка и цвет штампов — в настройках модуля, можно добавлять свои (белые .webp с прозрачностью).
- **Журнал событий** для ГМ: находки, неудачные поиски, передачи, выкладка на доску, выдача, дела — одной лентой с фильтрами.
- **Экспорт и импорт** данных ГМ в JSON с сохранением id.
- **Руководство ГМ** — журнал в компендиуме модуля.

## Права

| Действие | ГМ | Профайлер | Игрок |
|---|---|---|---|
| Шаблоны, типы, зоны | да | нет | нет |
| Поиск улик | да | да | да |
| Выдача, правка и удаление улик игрока | да | нет | нет |
| Передача своих улик | нет | да | да |
| Досье: создание и правка | да | да | чтение |
| Создание дел | да | по настройке | нет |
| Правка дел и таймлайна | да | да | чтение |
| Удаление карточек доски | да | нет | нет |
| Папки в списке улик | у любого игрока | свои | свои |
| Папки в деле | да | да | чтение |
| Версии | решает | выдвигает, видит свои | нет |
| Прогресс дела | всё | только найденное | нет |

Профайлеры назначаются в настройках модуля. Ограничения держатся на правах Foundry: игрок пишет только в свои флаги, общие журналы принадлежат ГМ и профайлерам, а действия через ведущего (socketlib) проверяются на стороне ГМ.

## Что требует ведущего в сети

Создание нового дела или досье профайлером и, если у роли игрока нет прав «Рисунки», «Обзор файлов» и «Загрузка файлов», создание и правка чужих карточек доски. Поиск, список улик, заметки, обмен и правка уже созданных дел и досье работают без ГМ.

## Шрифты

Шрифты карточек с кириллицей (Caveat, Marck Script, Neucha, Bad Script, Amatic SC, PT Mono, IBM Plex Mono, Fira Mono, Roboto Mono) лежат в модуле по лицензии SIL OFL 1.1 (`assets/fonts/LICENSE-OFL.txt`). Карточки со шрифтами прототипа без кириллицы автоматически получают замену того же стиля.
